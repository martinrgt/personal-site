Welcome to this website.

After a few months of studying [Hugo](https://gohugo.io/)'s possibilities to do a static website, and a couple of months building it and writing its primary content (both in French and English), here we are!

# Follow the Guide
This website is made of three main parts.
- In the [Games](/games/) section, you'll find all the games I've worked on, either as a game designer, a narrative designer, a translator or every other role.
- In the [Research](/pages/research) page, I listed all my academic works. This section might become more detailed one day.
- In the [Blog](/posts/), you can read short pieces like this one.
- If I make things right, you may also navigate through my pages with tags. It'll let you see topics in a transversal way, no matter the section.[^1]

# Why a New Website?
You might be wondering why I bothered making a new website with a whole new tool when the previous one worked. First, I'm not sure people ever visited it—although I should really start monitoring those data—, so I can assume no one will miss it. I made this website for a few personal reasons I shall elaborate on in the next blog posts (when they come).

## Seeking Other Features
The previous site was great and pretty, but was missing a few things I needed.
- A blog space to yap about various things (new stuff I learn, new thoughts worth sharing), whenever I wanted.
- Multilingual pages. Currently, I'm writing them in English and in French. Eventually, if needed, I might translate everything in Italian.
- A proper structure, with pages, tags, and navigation tools I only have to worry about once. Carrd is very static and every button, every link, needs to be placed by hand.

## From Proprietary to Open Source
Making this website is part of a broader movement in my life that consists in shifting away from proprietary software, and more specifically GAFAM solutions. It started back in the summer of 2025 with ditching the Office Suite (or, should I say, Microsoft 365 Copilot, I guess?) and replacing it with Only Office, then LibreOffice, quickly followed by unsubscribing from Xbox Game Pass and starting buying and owning my games again (on other platforms). Then came Linux and all the rabbit-hole you can imagine, but it's a story for another time.

In the middle of this process, my site still depended on proprietary software, [Carrd](https://carrd.com/). It is a great, lightweight, rather cheap, and efficient solution, and I don't hold any grudge against them. Kudos to them ❤️

Unfortunately, for now this website will be hosted on GitHub Pages. So much for ditching proprietary solutions. But as soon as I learn self-hosting my own website, It'll change!

More importantly, I was eager to learn new things.

## Learning Things
I love learning new things. Or, more specifically, I love discovering new tools.

I wrote my PhD dissertation using [LaTeX](https://www.latex-project.org/), even if I had absolutely no reason to do so. I had zero math to write, people at the Italian Studies Department had no idea what LaTeX is, and some didn't even know how to use WYWIWYG (What You See Is What You Get) word processing software properly. But, you know, I was curious. And I wanted to find the perfect solution to the absurd citation rules, full of Latin abbreviations and conditional formatting that no one thought to automate.[^2]

Then, game development lead me to discover a whole new range of possibilities. From Git to Unity and Godot, it was a bliss learning those things. And I would like this website to be the place where I document my discoveries.

# About LLMs
I could not, in 2026, start a new digital project without thinking about LLMs. When I mentioned my project to some people, they asked me why I didn't use an LLM to create it and implement it, which would have probably saved me a month or two.

The problem is that using LLMs here defeats the purpose of learning things. Understanding Hugo was tricky; getting to have my first PaperMod site running was also a challenge. The only place where I used an LLM was to browse PaperMod's wiki, only when browsing the web for answers to my many dumb questions was ineffective. But often, this solution led me to try overly complex solutions.

The same for writing and images. I don't want an LLM to write for me in English, and I don't want an LLM to generate insipid cover images for my blogposts, as I'm already seeing too many on the web.

I hope this will be the first of many blogposts in the future. Long live this website!
